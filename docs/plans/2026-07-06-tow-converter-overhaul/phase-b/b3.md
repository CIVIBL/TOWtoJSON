# B3: Fix magic item placement (character vs champion vs banner)

**Avoid:** Don't attach a character's items to the first command entry with a matching magic slot — that's the current bug (character items land on unit champions). Placement is decided by WHERE the item was tokenized (main line = the character/unit itself; champion sub-line = champion) and by item type (banner = standard bearer).

**Depends on:** B1's `items: [{name, data, fromChampion}]` flag.

## Steps

### Step 1: Write failing tests (extend test/generate.test.js)

1. Grey Seer (character): Storm Daemon + Ruby Ring of Ruin land in `unit.items[*].selected`, chosen by `slot.types.includes(item.type)`; `unit.command` untouched by items.
2. Plague Monks with `Banner Of Verminous Scurrying` on the main line: Standard Bearer command entry active with the banner in `command[i].magic.selected`; not in champion slot.
3. A unit with a champion bullet carrying an item (`fromChampion: true`): item lands on the champion command entry's `magic.selected`.
4. Selected-item shape matches reference-files/tree-army_owb.json (compare a real `selected` entry there and assert the same keys — read the reference before writing the assertion).

### Step 2: Implement in src/js/generate.js buildUnit()

Order of placement per item:
1. `item.data.type === 'banner'` and unit has a Standard Bearer with `magic.types.includes('banner')` → place there.
2. `item.fromChampion` → champion command entry with `magic.types.includes(item.data.type)`.
3. Otherwise → `unit.items` slot where `slot.types.includes(item.data.type)`; fallback: slot whose `name_en` contains 'magic'.
4. No slot found → do NOT drop silently; push to `unit.__unplacedItems` (array of names) — D1 reads this for warnings. Strip `__unplacedItems` from the final JSON in `generateOWBJson` after reporting hook (keep it on the returned matched-unit metadata instead if simpler).

### Step 3: Green, full suite, manual OWB import

`npm test`, then convert the Skaven fixture in the browser and import the JSON at old-world-builder.com — Grey Seer must show both items, Plague Monks the banner.
