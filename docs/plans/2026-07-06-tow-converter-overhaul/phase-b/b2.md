# B2: Scope magic item index to the detected faction

**Avoid:** Don't index all 40 top-level keys of magic-items.json — that's the current bug (a Skaven list can match Bretonnian virtues, producing illegal picks OWB rejects or misrenders).

## Steps

### Step 1: Write failing tests (test/items.test.js)

- `buildMagicItemIndex(magicItems, 'skaven')` contains 'storm daemon' and 'warpstone amulet' and general items ('talisman of protection', 'ruby ring of ruin'); does NOT contain any name from `magic-items.json['knightly-virtues']` or `['vampiric-powers']`.
- `buildMagicItemIndex(magicItems, 'wood-elf-realms')` contains forest-spites and kindreds entries.
- Names are normalized (asterisks stripped, lowercased).
