### Step 2: Implement tokenizer + classifier in src/js/match.js

New shape (keep the same result object so generate.js is untouched):

```js
export function tokenizeUnitBlock(block) {
  // returns { mainTokens: string[], subLines: [{count, label, tokens: string[]}] }
  const lines = block.split('\n').map(l => l.trim()).filter(Boolean);
  const main = lines[0]
    .replace(/^\d+\s*-\s*/, '')          // strip "465 - "
    .replace(/\s*\[\d+\s*pts?\]$/i, ''); // strip "[225 pts]"
  const mainParts = main.split(',').map(s => s.trim()).filter(Boolean);
  const mainTokens = mainParts.slice(1); // parts[0] is the unit name
  const subLines = [];
  for (const line of lines.slice(1)) {
    const m = line.match(/^[•\-\*]?\s*(?:(\d+)x?\s+)?(.+)$/);
    if (!m) continue;
    const parts = m[2].split(',').map(s => s.trim()).filter(Boolean);
    subLines.push({ count: m[1] ? parseInt(m[1], 10) : 1, label: parts[0], tokens: parts.slice(1) });
  }
  return { mainTokens, subLines };
}
```

`classifyToken(token, unit, itemIndex)` — try in priority order, first hit wins:
1. wizard-level regex (existing pattern) → `{type:'wizard', level}`
2. lore list (existing) → `{type:'lore'}`
3. `unit.command` — normalized equality, then singular/plural, then startsWith
4. `unit.mounts` → same comparison ladder
5. `unit.equipment` / `unit.armor` (respect `requiredMagicItem` guard from current code)
6. `unit.options` incl. nested
7. `itemIndex` — exact normalized match first; then unique prefix match (token startsWith itemName or itemName startsWith token, minimum 5 chars, and only if exactly one candidate matches)
8. else `{type:'unknown'}`

Comparison ladder helper (replaces nameMatchesInContext for tokens):

```js
function tokenEquals(token, name) {
  const t = norm(token), n = norm(name);           // norm: lowercase, strip *, collapse spaces
  if (t === n) return true;
  const ds = s => s.endsWith('s') && !s.endsWith('ss') ? s.slice(0, -1) : s;
  return ds(t) === ds(n);
}
```

`extractOptions(block, unit, itemIndex)`:
- tokenize; classify `mainTokens` and each token of sub-lines whose `label` matches the unit name or a command entry (e.g. `30x Clanrat, Shield, ...` → Shield applies to unit; champion bullet tokens apply and remember `fromChampion: true` on matched items — B3 consumes this)
- sub-lines whose label matches a detachment unit are returned untouched for `extractDetachments`
- return the existing result shape plus `unknownTokens: string[]` and `items: [{name, data, fromChampion}]`

Keep exports `matchUnitName` (unit-name matching is unchanged) and keep `nameMatchesInContext` only if still referenced; otherwise delete it.
