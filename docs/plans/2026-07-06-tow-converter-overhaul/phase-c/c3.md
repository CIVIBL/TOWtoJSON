**Avoid:** Don't fetch all 17 faction files on page load for detection — fetch only `unit-name-index.json` (+`army-compositions.json`) up front; faction file loads stay lazy on convert/AoI-check.

## Steps

### Step 1: Update index.html

- On first input, fetch `src/data/owb/unit-name-index.json` and `src/data/owb/army-compositions.json` (cache like factionDataCache).
- `updateArmyComposition` calls `detectFaction(text, unitNameIndex)`; populate dropdown from `getArmyCompositions(slug, compositions)` — values are the official slugs verbatim.
- AoI hint/auto-select from `detectArmyOfInfamy(...)`.
- When detection returns null but text is non-empty, show a manual faction `<select>` (all 17 factions) instead of hiding the composition section — currently the user gets a hard error with no recourse.

### Step 2: Manual verification

`npm run serve`, then via preview tools:
1. Skaven fixture → faction Skaven, dropdown shows official Skaven compositions.
2. Same fixture minus the `Skaven` header line → still detected.
3. Gibberish text → manual faction picker appears, conversion possible after picking.
4. Convert and import the JSON at old-world-builder.com with a non-default composition selected — list opens under the right composition.
