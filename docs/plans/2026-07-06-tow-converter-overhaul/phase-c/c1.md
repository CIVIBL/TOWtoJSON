# C1: Build script for unit-name index and official army-composition slugs

**Avoid:** Don't hand-type composition slugs — the apostrophe bug (`orion's-wild-hunt` vs OWB's real `orions-wild-hunt`) came from generating slugs by string-munging. Slugs must be copied from OWB's own data.

## Steps

### Step 1: Get the official composition list from the OWB repo

Fetch the OWB games/armies definition. Try, in order:
1. `WebFetch https://raw.githubusercontent.com/nthiebes/old-world-builder/main/public/games/the-old-world.json`
2. If 404, shallow-clone `https://github.com/nthiebes/old-world-builder.git` to a temp dir and `grep -rl "host-of-talsyn" public/` to locate the file that enumerates armies and their compositions (it exists — the site's army-composition picker is driven by it).

Verification of the right file: it must contain `orions-wild-hunt` and per-army composition lists.

### Step 2: Write scripts/build-data.mjs

Node script, no dependencies:
- **unit-name-index.json**: iterate `src/data/owb/*.json` (skip magic-items.json); for each unit in characters/core/special/rare/mercenaries/allies emit `normalizedName -> [factionSlug, ...]` plus singular/plural variants (reuse `generateNameVariations` from src/js/parse.js by importing it). Also emit `"__unitCounts": {factionSlug: n}` for score normalization.
- **army-compositions.json**: transform the OWB armies file into `{ factionSlug: [{slug, name}] }`, first entry always the Grand Army (slug = faction slug). Embed the source URL and retrieval date in a `"__source"` key.

If the OWB armies file cannot be located, fall back to the union of `armyComposition` values found in `src/data/owb/*.json` + known AoI display names, and print a loud warning — but exhaust step 1 first.

### Step 3: Generate, spot-check, commit

`node scripts/build-data.mjs`. Check: `unit-name-index.json` has `clanrats -> ['skaven']`; `army-compositions.json['wood-elf-realms']` includes `host-of-talsyn` and `orions-wild-hunt`; skaven has its Infamy lists (Pestilens etc.) with whatever slugs OWB actually uses.

Commit generated files + script: `feat: generated unit-name index and official composition slugs`
