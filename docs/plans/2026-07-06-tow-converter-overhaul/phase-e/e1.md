# E1: Build NR catalogue index from .cat/.gst files

**Avoid:** Don't try to ship or parse raw .cat XML in the browser — the files are huge and deeply cross-referenced. All XML handling happens at build time in Node; the browser gets small pre-digested JSON.

**Avoid:** Don't invent UUIDs. Every id in the output must be copied from the .cat/.gst source; NR resolves selections against the community catalogue by these exact ids.

## Steps

### Step 1: Get the source data

Shallow-clone `https://github.com/vflam/Warhammer-The-Old-World.git` to a temp dir (do not commit it). Identify the `.gst` file (game system) and per-faction `.cat` files. Cross-check ids against `reference-files/In_The_Pines_-_Logan_s_Lair_-__To_Test_.json`: its `gameSystemId` must equal the .gst id, and its force `catalogueId` must equal the Wood Elves .cat id — this proves the repo matches what NR uses.

### Step 2: Write scripts/build-nr-data.mjs

`npm i -D fast-xml-parser` (devDependency only). Parse and emit:

- `src/data/nr/game-system.json`: `{ gameSystemId, gameSystemName, gameSystemRevision, costTypeId }` (the points cost typeId from the .gst) plus the category entryIds for Characters/Core/Special/Rare.
- `src/data/nr/<faction>.json`:

```json
{
  "catalogueId": "...", "catalogueName": "...", "catalogueRevision": 0,
  "units": [{
    "name": "Grey Seer", "entryId": "...", "type": "unit|model",
    "costs": [{"typeId": "...", "value": 0}],
    "categoryEntryIds": ["..."],
    "options": [{"name": "...", "entryId": "...", "groupId": "...", "costs": [...],
                  "children": [...] }]
  }]
}
```

Walk `selectionEntry` / `selectionEntryGroup` / `entryLink` recursively; resolve `entryLink.targetId` against shared selection entries. Only keep fields needed to emit a roster selection (name, ids, costs, constraints max where present).

### Step 3: Generate for skaven and wood-elf-realms, validate

`node scripts/build-nr-data.mjs --faction skaven --faction wood-elf-realms`. Validate: every unit in the OWB skaven data has a same-named (after normalization) entry in the NR index — print a diff of misses; misses are acceptable but must be listed in the script output. Wood Elves index must contain the entryIds used in the reference roster (grep a few, e.g. the Glade Lord selection's entryId).

Add a `"build:nr"` script to package.json. Commit script + the two generated faction files: `feat: NR catalogue index build script`
