# E2: NR roster generator

**Avoid:** Don't reverse-engineer the roster shape from documentation — mirror `reference-files/In_The_Pines_-_Logan_s_Lair_-__To_Test_.json` field-for-field. NR is tolerant of missing optional fields but strict about ids, `costs`, and the `selections` nesting.

## Steps

### Step 1: Write failing tests (test/generate-nr.test.js)

- Top level: `roster.gameSystemId` matches game-system.json; `roster.forces[0].catalogueId` matches skaven index; `costLimits`/`costs` present with points typeId.
- Convert the Skaven fixture through the full pipeline with `generateNRJson`: 10 entries produce selections (or fewer with each miss reported in the return's `warnings`); Clanrats selection has `number: 31` on its model child and command upgrades as child selections; Grey Seer has wizard-level and item selections.
- Total roster cost equals the sum of selection costs (self-consistency, not equality with 2197 — NR points come from the catalogue).
- Round-trip structure check against the reference roster: same top-level keys, same selection object keys.
